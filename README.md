# Project Title

Ecommerce API

## Description

The Ecommerce API is crafted to provide a smooth and user-friendly shopping experience, complemented by powerful administrative features. It encompasses fundamental functionalities, including user registration, authentication, product listing, shopping cart management, order placement, and a detailed order history.

For users, the API ensures an effortless journey—from registration to exploring products, managing their shopping carts, placing orders, and reviewing detailed order histories.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Make sure you have installed all of the following prerequisites on your development machine:

* Git [Download & Install Git](https://git-scm.com/downloads)
* Visual Studio Code [Download & Install Visual Studio Code](https://code.visualstudio.com/).
* Python 3.12 [Download & Install Python 3.12](https://www.python.org/downloads/).
* Postman API Platform [Download & Install Postman API Platform](https://www.postman.com/).

### Installing

* Clone github repository

```bash
$ git clone https://github.com/fayizabeegam/Ecommerce_API.git
```

* Create a virtual environment

```bash
python -m virtualenv venv
```

* Install requirements.txt

```bash
pip freeze > requirements.txt
```

* Run server

```bash
python manage.py runserver
```
